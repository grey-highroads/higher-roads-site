Steve Taylor Presents Website Setup Guide

Goal

Create a client website stack using GitHub, Cloudflare Pages, Decap CMS, and GitHub OAuth.

GitHub Repository
        ↓
Cloudflare Pages Hosting
        ↓
Decap CMS Editing Interface
        ↓
GitHub OAuth Authentication

Phase 1: Create GitHub Repository

Create repository:

steve-taylor-presents

Use this structure:

steve-taylor-presents/

├── index.html
├── styles.css

├── admin/
│   ├── index.html
│   └── config.yml

├── content/
│   └── homepage.yml

└── functions/
    └── api/
        ├── auth.js
        └── callback.js

Important: use functions/api, not functions/API. Cloudflare routes are case sensitive.

Phase 2: Create Basic Website

Create index.html:

<!DOCTYPE html>
<html>
<head>
  <title>Steve Taylor Presents</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <h1>Steve Taylor Presents</h1>
  <p>Website coming soon.</p>
</body>
</html>

Phase 3: Deploy Cloudflare Pages

Cloudflare steps:

  1. Workers & Pages
  2. Create application
  3. Pages
  4. Connect GitHub
  5. Select repository

Build settings:

Framework preset: None
Build command: blank
Output directory: /

Phase 4: Add Decap CMS

Create admin/index.html:

<!doctype html>
<html>
<head>
<meta charset="utf-8" />
<title>Content Manager</title>
</head>
<body>
<script src="https://unpkg.com/decap-cms@3.0.0/dist/decap-cms.js"></script>
</body>
</html>

Create admin/config.yml:

backend:
  name: github
  repo: YOUR-GITHUB-USERNAME/steve-taylor-presents
  branch: main

media_folder: "images/uploads"
public_folder: "/images/uploads"

collections:
  - name: pages
    label: Pages
    files:
      - label: Homepage
        name: homepage
        file: content/homepage.yml
        fields:
          - label: Headline
            name: headline
            widget: string
          - label: Button Link
            name: button_link
            widget: string

Create content/homepage.yml:

headline: "Welcome"
button_link: "https://example.com"

Phase 5: Test Decap Loading

Open:

https://steve-taylor-presents.pages.dev/admin/

Decap loading and authentication are separate. Authentication will fail until OAuth is configured.

Phase 6: Create GitHub OAuth App

GitHub:

  1. Settings
  2. Developer Settings
  3. OAuth Apps
  4. New OAuth App

Homepage URL:

https://steve-taylor-presents.pages.dev

Authorization callback:

https://steve-taylor-presents.pages.dev/api/callback

Leave Device Flow disabled.

Phase 7: Cloudflare Environment Variables

GITHUB_CLIENT_ID

Type: Text

GITHUB_CLIENT_SECRET

Type: Secret

Phase 8: Add Cloudflare OAuth Functions

Create:

functions/
└── api/
    ├── auth.js
    └── callback.js

Do not create an empty [...path].js file when using this structure.

Phase 9: Update Decap Config

backend:
  name: github
  repo: YOUR-GITHUB-USERNAME/steve-taylor-presents
  branch: main
  base_url: https://steve-taylor-presents.pages.dev
  auth_endpoint: /api/auth

Phase 10: Deploy and Test

https://steve-taylor-presents.pages.dev/admin/

Expected flow:

Decap CMS
↓
GitHub OAuth
↓
Authorization
↓
Return to Decap
↓
Edit content
↓
Commit to GitHub
↓
Cloudflare rebuild

Lessons Learned

  • Cloudflare Pages deployment was simple. Authentication was the complex part.
  • Decap plus Cloudflare requires OAuth setup.
  • This setup requires client users to have GitHub accounts.
  • For nontechnical clients, evaluate a more client-friendly CMS option.
